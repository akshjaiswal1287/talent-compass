# TalentCompass product proposal

TalentCompass is a privacy-first technical-screening workspace for recruiters. A candidate provides resume content; the service removes direct identifiers before analysis, returns skills and a merit score, and lets the candidate prove that the score clears a hiring threshold through a Midnight circuit. The recruiter can verify threshold eligibility without receiving the resume input used to produce it.
